# 连接器合同

Excel Ops 将业务逻辑与存储平台分开。即使底层平台行为不同，每个连接器也应提供等价的安全能力。

| 连接器 | 读取模型 | 写入模型 | 冲突保护 |
|---|---|---|---|
| 本地 XLSX/CSV | 文件快照 | 新文件或经过授权的替换 | Hash 与修改时间 |
| 本地同步目录 | 本地文件与同步状态 | 同目录新文件，再由客户端同步 | Hash、修改时间与同步观察 |
| Dropbox API | 带版本的文件 | 使用预期 revision 上传 | 远端 revision |
| Google Sheets | 范围与元数据 | 批量范围/文档更新 | 快照与写后回读 |
| 飞书表格 | Sheet 范围 | 平台 API 写入 | 可用时使用文档版本与回读 |
| WPS 表格 | 对应类型的范围 | 平台专用批量写入 | 文件类型、版本与回读 |

每个连接器在修改前都必须支持 dry-run change set，在修改后必须验证实际保存状态。如果平台无法提供安全替换语义，应创建副本并返回可审核的交付，而不是声称已经原地更新。

平台凭据属于部署环境，绝不能进入 recipe 或仓库 fixture。
