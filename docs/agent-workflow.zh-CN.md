# Agent 工作流

Excel Ops 把对话作为产品界面。用户说明想要的结果并提供来源；Agent 负责内部路由和工具选择。

```text
用户意图与来源
        ↓
权威来源与目标检查
        ↓
快照与操作计划
        ↓
提取 → 标准化 → 匹配
        ↓
Accepted ───────────────→ 写入
Review ─→ 人工选择 ─────→ 写入
Rejected ───────────────→ 报告
        ↓
重新读取实际保存的目标
        ↓
对账 → 打包 → 可复用 recipe
```

## 自动化边界

Agent 应自动完成确定性工作，不应每一步都要求确认。只有当决定可能实质改变结果时才暂停：来源权威性冲突、身份匹配歧义、破坏性覆盖、不支持的公式行为或云端 revision 冲突。

图片中某个值无法辨认，不等于要求用户重做整个任务。Agent 应完成安全记录，只把不确定的单元格放进最小人工复核队列。

## 请求示例

> 使用 `$excel-agent` 读取这些巡检截图，与上周工作簿进行匹配，更新当前周期，并交付经过检查的副本。不要猜测无法辨认的标识符。

预期结果：

- 更新后的工作簿或云端表格；
- accepted、review 和 rejected 数量；
- 从来源到输出的追溯关系；
- 对实际保存结果的验证结论；
- 下一周期可以复用且不含凭据的 recipe。
